# 第二阶段：学习试用版功能与排期

- 状态：规划草案，功能和数字均为建议值，不代表已经实现或验证。
- 更新日期：2026-10-22
- 依据：[产品总规划](product-design-and-roadmap.md)、[视觉规范](visual-design-guidelines.md)
- 前置阶段：第一阶段本地 Demo 完成验收。
- 建议周期：4—6 周；本文件周次从本阶段启动日计算。

## 1. 目标与交付边界

让孩子可以连续学习两周以上，在复习中保留所学，并开始使用古诗意象表达自己的想法。上线 Go 服务，但继续支持不登录、离线完成核心学习。

本阶段继续以小四至小六为主，兼顾中一基础复习。保留“今天／诗库／我的”三个主导航，创作从学习完成页和“我的诗集”进入。

### 进入本阶段前需要核对的现状

当前客户端 README 描述朗读暂用设备语音，释义与读音仍待教师审核。该说明不是正式内容验收结果。第二阶段试用发布前，应完成已发布篇目的审核和内置录音交付，不能把系统语音效果视为已经完成粤普录音。

原规划的复习间隔为初次通过后第 1、3、7 天；当前 README 描述已延伸至 14、30 天。实施时先确认实际数据结构，迁移已有复习记录，再调整规则，避免重置用户进度。

### 不进入本次交付

真人多人对战、好友体系、公开作品社区、班级管理、AI 自动评诗、订阅商城。账号与同步是可选服务，不作为孩子开始学习的门槛。

## 3. 功能规则

### 3.1 诗库与离线包

推荐主题包括月与思乡、山水田园、四季景物、友情送别、生活与志趣。最终篇目由内容负责人结合香港目标年龄审核确定，不宣称对应全部学校教材。

每首正式发布的诗至少包含：

- 繁简正文、作者、朝代、稳定的诗句标识和正文版本。
- 逐句浅释、重点字词、全诗理解，以及可展开的进阶解释。
- 粤语与普通话审核录音、逐句播放信息。
- 至少 5 道练习，覆盖理解和记忆，并为每题提供解释。
- 难度、主题、意象、出处及素材授权信息。

新增诗篇分包上线；“总量 30 首”指完成审核的学习包，不用只有正文的篇目充数。优先补齐现有内容，再扩充总量。

下载展示预计大小和进度。内容与音频采用同一发布清单，校验完成后切换版本；失败保留旧包。删除下载包只释放资源，不删除学习记录、收藏或作品。内置基础包始终可用。

### 3.2 每日计划与复习

用户可选择每天约 5、10、15 分钟的学习目标，作为任务量建议，不强制计时。默认推荐“到期复习优先，再学一首新诗”。积压较多时允许分日处理，不要求一次清空。

建议初始规则：

1. 一次练习包含理解和记忆题；总正确率达到 80%，且两个维度都至少答对一题，记为本次通过。
2. 当次首次提交的结果用于学习判断；查看答案后的重试单独记为订正，不覆盖首次结果。
3. 借助提示完成的答案标为“有提示完成”，用于推荐复习，不等同于独立回忆。
4. 初次通过后安排第 1、3、7、14、30 天的复习节点；各节点相对于本轮初次通过日期计算。
5. 跨日复习未通过时，次日重试当前节点；通过后进入下一个节点。已过期节点不在同一天补做多次，而从下一个学习日起重新安排。
6. 至少完成两次不同日期的无提示复习，且首次通过至最近一次复习跨度达到 7 天，才展示“记忆较稳”。

具体阈值通过试用调整，并保存规则版本。已有学习记录保留，规则升级不把过去获得的奖励清零。

### 3.3 错题回看

区分“字词不理解”“诗意判断”“顺序记忆”“诗句补全”等类别。错题页先展示对应原句，再解释错误原因，最后提供一道同知识点练习。只有一道题时注明是再次练习，不伪装成新题。

跨日独立答对后可移出“待巩固”，历史记录仍保留。题目修正或撤回后，旧记录显示当时版本；无效题不继续影响当前学习判断。

### 3.4 小小诗人

入口为“我的 → 我的诗集”和主题学习完成页的“试着写两句”。

流程：选主题 → 看一条例句 → 选择意象词 → 写两句或四句 → 查看字数与主题提示 → 命名保存。

- 模式包括仿写和自由写，作品明确标注类型；例句标注原作者和出处。
- 字数按汉字计算，忽略标点和空白；五言／七言只检查所选句式的字数。
- 主题词命中只是提示，不判定作品优劣，不要求必须使用词库中的词。
- 输入时自动保存草稿；返回、切后台、重启后可以继续。
- 用户可修改、复制、删除作品；删除前可撤销或确认。
- 默认仅本人可见，不提供公开发布、点赞、评论。
- 押韵、平仄和审美评价不纳入本批自动评分。

### 3.5 家长账号、档案与同步

儿童无需填写手机号、真实姓名、学校或生日。家长区域管理账号与儿童档案；年级或学习阶段为可选推荐依据。家长入口验证与真正的服务端身份认证分开处理，简单算术题不作为账号认证。

一个家长账号可关联多个儿童档案，各档案记录独立。游客首次绑定时，由家长明确选择归入哪个儿童档案，展示待迁移的篇目与作品数量。重复操作不得生成重复记录。

同步规则：

| 数据 | 合并策略 |
| --- | --- |
| 学习事件 | 使用稳定事件 ID 去重，保留原始事件，由规则计算当前状态 |
| 收藏和设置 | 使用服务端修订号确认变更；界面文字与朗读偏好可保持设备本地 |
| 创作草稿 | 同一作品发生并发修改时保留两个版本，供家长或孩子选择，不静默覆盖 |
| 删除记录 | 使用删除标记传播，防止旧设备重新上传后复活 |
| 游客数据 | 迁移确认后标记归属，重复绑定不重复计入进度 |

弱网时先本地保存并显示“待同步”；恢复网络后重试。退出账号后不得向下一位使用者展示上一个账号的私有记录。账号删除流程覆盖关联档案与云端作品，并在确认页说明本地缓存处理方式。

### 3.6 家长周报与诗境配对

家长周报分别呈现理解、记忆与复习，不将阅读时长等同于掌握。样本不足时显示“记录还不够”，不推断能力高低。报告附一条可执行陪学建议，例如“请孩子解释这首诗中的月亮让诗人想到了什么”。

诗境配对先用一个主题验证：孩子选择与诗句相符的画面，再指出依据。插画不得扭曲诗意，例如把“疑是地上霜”画成真实积雪。画面答对但依据答错时分别反馈。

## 4. 页面与状态

| 页面 | 主要内容 | 关键状态 |
| --- | --- | --- |
| 今天 | 目标设置、到期复习、继续学习 | 无记录、积压、今日完成、离线 |
| 主题包详情 | 篇目、难度、资源大小、下载 | 未下载、下载中、可用、更新失败 |
| 错题回看 | 原句、原因、订正练习 | 无错题、待巩固、题目已修订 |
| 创作编辑 | 例句、意象、输入、字数、保存 | 空稿、自动保存、恢复草稿、冲突副本 |
| 我的诗集 | 作品封面、主题、修改日期 | 无作品、草稿、完成作品 |
| 家长区域 | 档案、周报、同步、账号管理 | 游客、已登录、待同步、数据不足 |

延续黄蓝绘本风格与贝贝南瓜角色；编辑与阅读页控制装饰密度，角色不遮挡诗文和键盘输入区。

## 5. 客户端、Go 与内容分工

| 责任方 | 工作 |
| --- | --- |
| Swift | 本地内容包、下载与校验、复习队列、创作编辑、家长页面、同步队列、状态呈现 |
| Go | 内容发布清单、资源授权、身份验证、档案权限、事件去重、同步修订、删除处理、统计汇总 |
| 内容 | 选诗、繁简与释义校对、题目解释、粤普录音、主题与意象标注 |
| 产品／设计 | 难度与阈值、作品流程、家长报告、空态与错误文案、试用观察 |

Go 初期采用模块化单体服务。结构化数据可使用 PostgreSQL，音频与图片使用对象存储；具体部署区域和供应商在发布前结合实际需求选定。无需为本阶段先拆微服务。

内容发布初期可使用受控导入工具与审核清单，不把完整可视化 CMS 作为四至六周排期的前提。审核状态至少包括草稿、待审核、通过、已发布、已撤回；发布权限与普通学习账号隔离。

## 6. 排期与依赖

假设：1 名 Swift 工程师、1 名 Go 工程师并行，产品／设计、中文教师及音频制作同步支持；第 5—6 周安排测试支持。人员不足或录音产能未确认时重新估算。

| 周次 | Swift／产品 | Go／内容 | 里程碑 |
| --- | --- | --- | --- |
| 第 1 周 | 核对 Demo 缺口、定义学习状态和作品结构、交互稿 | 内容与事件协议、审核现有 12 首、确定新增篇目 | 数据与交互范围冻结 |
| 第 2 周 | 复习与错题、内容包下载 | 发布清单、资源交付、内容录入与审核 | 旧包保留、新包可更新 |
| 第 3 周 | 创作编辑、诗集、离线恢复 | 内容发布与回滚、基础统计；并行启动账号能力 | 本地学习与创作可连续使用 |
| 第 4 周 | P0 回归与小规模试用 | 30 首审核交付、服务异常验证 | P0 学习试用版 |
| 第 5 周 | 账号、档案、同步及家长报告 | 档案权限、同步去重、周报汇总 | P1 账号与双设备流程 |
| 第 6 周 | 诗境配对、双设备与升级测试、问题修复 | 删除流程、失败恢复、试用数据核对 | 完整目标发布 |

四周版本可先交付 P0；六周版本加入 P1。任何情况下，内容审核、数据保存与恢复不能被当作可裁减项。

## 7. 验收标准

- [ ] 既有用户升级后，收藏、学习记录、复习节点和文字偏好保留。
- [ ] 30 首正式学习内容完成校对；粤普音频、正文与练习版本一致。
- [ ] 下载中断或校验失败时，旧内容包和已保存记录仍可使用。
- [ ] 飞行模式下可学习已下载篇目、复习、写诗和恢复草稿。
- [ ] 复习跨日、逾期、失败重试、题目撤回都有可复现的正确行为。
- [ ] 同日反复订正不会被记录为多次跨日独立通过。
- [ ] 繁简切换不改变创作原文，不丢失作者输入；古诗题目兼容审核过的繁简形式。
- [ ] P1 上线时，两设备重复上传不重复计分，并发作品修改保留副本。
- [ ] P1 上线时，切换儿童档案、退出和换账号不会串用私有数据。
- [ ] P1 上线时，家长能完成账号和云端数据删除流程。

## 8. 试用观察与下一阶段准入

建议邀请 20—30 个家庭进行两周试用，实际规模以招募条件为准。以下为观测口径，不预设已经达到的效果：

| 指标 | 口径 | 用途 |
| --- | --- | --- |
| 学习完成率 | 完成首次有效小测的人数／开始一首新诗学习的人数 | 发现流程中断 |
| 到期复习参与率 | 完成至少一项到期复习的用户日／存在到期任务的用户日 | 判断复习入口是否有效 |
| 跨日无提示通过率 | 无提示通过的跨日复习次数／有效跨日复习次数 | 观察记忆保持 |
| 两周再次学习 | 首次学习后的第二周至少完成一次有效学习的人数／可完整观察两周的人数 | 观察持续使用 |
| 创作完成率 | 保存至少两句作品的人数／进入创作并开始输入的人数 | 判断创作门槛 |

事件示例：`poem_learning_started`、`quiz_completed`、`review_completed`、`creation_saved`、`content_download_failed`、`sync_failed`。默认统计不包含作品正文、自由输入全文和真实身份信息。

进入第三阶段前，应完成 P0 验收；在线多人还依赖 P1 账号、档案权限和服务稳定。若孩子普遍不理解释义或复习流程，应先修复学习问题，再增加社交玩法。
