# 贝贝古诗：产品功能设计与分阶段排期

- 文档状态：产品设计初稿
- 更新日期：2026-10-22
- 目标市场：香港中小学群体
- 客户端：Swift，苹果平台独占，兼顾 iPhone / iPad
- 后端：Go，第一阶段不接入后端

## 1. 产品定位与阶段目标

贝贝古诗是一款面向香港中小学生的古诗学习 App，帮助孩子把古诗读懂、记住，并能在游戏和表达中用出来。

核心学习闭环：

**选一首诗 → 理解诗意 → 分段记忆 → 小测巩固 → 在游戏中运用 → 看见进步 → 跨日复习。**

第一阶段的目标是做出可在真机完整演示的本地 Demo，验证核心学习体验。全部内容、音频、练习、游戏判题与学习记录均在本地运行，不包含后端、账号登录或在线多人服务。

## 2. 用户分层与香港市场适配

### 2.1 用户分层

| 用户阶段 | 主要需求 | 产品侧重点 |
| --- | --- | --- |
| 小一至小三 | 识字、听读、建立兴趣 | 短诗、大字、朗读、画面与简单配对 |
| 小四至小六 | 理解诗意、背诵、积累名句 | 逐句释义、重点字词、背诵练习、飞花令 |
| 中一至中三 | 理解意象、情感与表达手法 | 赏析、主题比较、进阶挑战、仿写 |
| 中四至中六 | 深入鉴赏、专题复习 | 修辞分析、比较阅读、论述练习，后续扩展 |

第一阶段优先服务小四至小六，并兼顾中一的基础复习。统一产品采用分层内容，避免同时为所有年龄段设计相同的难度与交互。

初期按年龄难度、主题、诗人组织内容，不假定香港所有学校使用同一套篇目。教材或学校篇目映射在后续阶段建立。

### 2.2 文字与朗读

文字版本和朗读语言是两组独立设置。

| 维度 | 设计要求 |
| --- | --- |
| 界面与文本 | 提供繁体中文、简体中文，香港用户默认繁体，允许手动切换 |
| 切换范围 | 界面、正文、释义、题目、答案解释与提示同步切换 |
| 朗读语言 | 提供粤语、普通话，与文字版本独立选择 |
| 内容校对 | 正文、异体字、多音字和注释需要人工审核，不仅依赖自动繁简转换 |
| 读音审核 | 粤语、普通话分别审核，古诗中存在特殊读音时保持注释与音频一致 |
| 学习记录 | 两种文字版本共用内容标识，切换后不丢失进度 |

例如，用户可以选择“繁体＋普通话”或“简体＋粤语”。

## 3. 核心学习功能

### 3.1 功能清单

| 功能 | 具体设计 | 学习价值 |
| --- | --- | --- |
| 诗库 | 按难度、主题、诗人、学习状态筛选；支持标题与诗句搜索 | 找到适合自己的内容 |
| 古诗阅读 | 标题、作者、朝代、正文；字号调整；繁简切换 | 提供清晰阅读入口 |
| 逐句释义 | 点击诗句展开“这句在说什么”，原句与解释对应 | 避免只会机械背诵 |
| 字词注释 | 点击重点字词，查看本诗语境中的含义与读音 | 解决理解障碍 |
| 全诗理解 | 展示诗中场景、主要情感与必要的写作背景 | 把零散诗句连成整体 |
| 朗读跟学 | 全诗播放、单句播放、重复播放；粤语／普通话切换 | 支持听读与模仿 |
| 分层背诵 | 完整正文 → 隐藏关键词 → 显示首字 → 隐藏全文 | 逐步降低提示 |
| 巩固小测 | 诗意配对、关键词填空、诗句排序、上下句补全 | 检查理解和记忆 |
| 错题回看 | 显示错误原因、对应释义与再次练习入口 | 让错误带来学习收益 |
| 复习计划 | 根据练习表现生成“今天建议复习” | 帮助形成长期记忆 |
| 学习记录 | 已学篇目、练习结果、复习状态、收藏 | 展示个人进步 |

以上为完整产品功能；第一阶段的具体范围以第 6 节为准。

### 3.2 释义设计

释义分为两层：

1. **读懂这句**：用孩子能理解的短句解释，默认展示。
2. **再想一想**：解释意象、情感或表达方式，按需展开。

以《静夜思》中的“疑是地上霜”为例：既要解释“好像地上铺了一层霜”，也要让孩子理解诗人看到的是月光。对应练习可以问“诗人眼前实际看到的是什么”，验证孩子是否理解，而非只记住翻译文字。

### 3.3 学习状态

| 状态 | 判定含义 |
| --- | --- |
| 已读过 | 完成阅读或听读 |
| 练习通过 | 达到本次练习要求 |
| 记忆较稳 | 经过跨日复习，仍能完成练习 |

背诵页可提供“我记住了”自评，但不能仅凭自评就标记为已掌握。自评与客观练习成绩分别记录和展示。

## 4. 游戏与创作功能

游戏直接调用已学古诗，让学习成果成为游戏能力。

### 4.1 玩法规划

| 玩法 | 具体规则 | 古诗元素 | 建议阶段 |
| --- | --- | --- | --- |
| 飞花令·单人 | 给出“月、花、春、山”等字，选择或输入含该字的诗句 | 关键词、名句、作者、出处 | 第一阶段优先 |
| 诗句拼图 | 把打乱的诗句或词组恢复顺序 | 诗句结构、对仗、全文记忆 | 第一阶段作为练习 |
| 诗境配对 | 根据诗句选择对应的场景或意象 | 月、柳、雁、落日等意象 | 第二阶段 |
| 小小诗人 | 按主题与字词提示完成仿写，保存作品 | 意象、句式、节奏、押韵启蒙 | 第一阶段可选，第二阶段完善 |
| 诗词接力 | 多人轮流补出下一句或完成指定主题诗句 | 上下句、主题联想 | 第三阶段 |
| 飞花令·对战 | 房间内轮流答题，不能重复已用诗句 | 诗句积累与快速回忆 | 第三阶段 |
| 合作修复诗卷 | 多名孩子分别完成字词、排序、释义任务，共同修复诗卷 | 理解、记忆、协作 | 第三阶段 |
| 主题赛季 | 围绕“春日”“山水”“思乡”等主题完成学习与挑战 | 诗歌主题与跨篇联系 | 第三阶段 |

### 4.2 单人飞花令

第一阶段建议提供两档：

- **入门模式**：给出四句诗，选择包含目标字的诗句。
- **挑战模式**：从已学诗句中输入答案，提供首字提示，默认不倒计时。

答题后展示出处，并提供返回对应诗句释义的入口。答错时给出解释与重试入口。

本地 Demo 仅验证内置诗库中的答案，明确提示“本轮范围：已学诗库”。未收录的诗句显示“暂未收录”，不能直接判成错误。繁简输入应映射到同一条诗句，避免因文字版本不同误判。

### 4.3 单人古诗创作：小小诗人

采用辅助创作流程：

1. 选择“秋天、校园、思念”等主题。
2. 从“月、风、叶、小路”等意象中选词。
3. 参考例句或句式写两句、四句。
4. 检查是否完成主题和字数要求。
5. 为作品起名，保存到“我的诗集”。

低龄阶段不强制平仄，不为作品给出貌似权威的审美分数。五言、七言、押韵等规则逐步引入，正式的近体诗格律学习放在进阶内容中。

第一阶段如加入此功能，仅提供主题、词库提示、文本输入与本地保存，不依赖在线生成或智能评诗服务。

## 5. 激励与排行榜

### 5.1 诗词成长册

以“诗词成长册”作为主激励。完成理解、背诵、复习任务后，收集诗词卡与主题徽章，例如学完一组含“月”的诗，解锁“月下诗人”。

| 行为 | 奖励方式 |
| --- | --- |
| 首次理解并完成一首诗的练习 | 获得诗词卡 |
| 完成跨日复习 | 提升卡片熟练度 |
| 修正错题 | 获得进步反馈 |
| 完成同主题多首诗 | 解锁主题徽章 |
| 完成原创或仿写 | 收入个人诗集 |

奖励对应有效学习行为。重复刷同一道题不能无限增加积分；漏学一天不清空已有成果。

### 5.2 排行分阶段上线

| 阶段 | 排行设计 |
| --- | --- |
| 第一阶段 | 个人最佳记录：本周完成篇目、复习次数、飞花令最高分 |
| 后续阶段 | 班级／好友周榜：学习进步、复习完成、游戏挑战等分类榜单 |
| 更后续阶段 | 在内容审核和儿童隐私机制具备后，评估公共创作展示与榜单 |

同伴榜单按年龄或难度区分，使用昵称，支持隐藏排名。本地 Demo 不展示伪装成真实用户的全球排行榜。

## 6. 第一阶段 Demo 范围

### 6.1 成功标准

孩子能够独立完成一首诗的理解与巩固，再用刚学到的诗句完成一次游戏；关闭 App 后，学习进度仍然保留。

### 6.2 优先级与交付范围

| 优先级 | 功能范围 | 第一阶段交付要求 |
| --- | --- | --- |
| P0 必须 | 繁体／简体 | 全流程切换，默认繁体 |
| P0 必须 | 本地诗库 | 建议 12 首，覆盖 3 个主题，难度适中 |
| P0 必须 | 古诗详情 | 正文、作者、逐句释义、字词注释、全诗理解 |
| P0 必须 | 朗读 | 12 首的粤语／普通话音频，随 App 内置 |
| P0 必须 | 背诵练习 | 关键词隐藏、首字提示、全文隐藏 |
| P0 必须 | 巩固小测 | 诗意配对、填空、排序，提供答案解释 |
| P0 必须 | 本地记录 | 学习进度、练习结果、收藏、设置持久保存 |
| P0 必须 | 简单复习 | 根据上次学习时间与错误记录推荐复习 |
| P1 推荐 | 单人飞花令 | 使用内置诗句，完成一局并保存个人最高分 |
| P1 推荐 | 成长反馈 | 学习完成页、诗词卡、简单进度展示 |
| P2 可选 | 小小诗人简版 | 主题、词库提示、文本输入、作品本地保存 |
| 暂不进入 | 在线能力 | 登录、云同步、真人多人游戏、好友、班级榜、公开发布 |

推荐演示组合为 P0 全部功能，加单人飞花令与简单成长反馈。P2 不作为第一阶段按期交付的前提。

### 6.3 内容交付

12 首诗在开发初期确定，优先选择适合目标年龄、能组成主题和飞花令题库的篇目。例如：

- 月与思乡。
- 山水田园。
- 四季景物。

每首诗必须具备完整的正文、逐句释义、重点字词、全诗理解、练习题、答案解释及双语朗读音频。现代释义、插画和录音应具备使用权。

内容准备、繁简校对与读音审核属于核心交付工作，应与客户端开发同步进行。

## 7. 信息架构与演示路径

### 7.1 主导航

| 主导航 | 页面内容 |
| --- | --- |
| 今天 | 继续学习、今日建议复习、推荐一首诗 |
| 诗库 | 全部古诗、主题分类、搜索、收藏 |
| 我的 | 成长册、个人最佳记录、设置；创作上线后加入诗集 |

飞花令放在首页与学习完成页，不为单个玩法单独增加主导航。

### 7.2 约 5 分钟的演示路径

1. 进入首页，打开《静夜思》。
2. 切换繁简文本，选择粤语或普通话朗读。
3. 点击“疑”“霜”，查看释义。
4. 完成一道诗意题，再进行关键词隐藏背诵。
5. 完成小测，收到下一次复习提示。
6. 进入“月”字飞花令，用刚学的诗句答题。
7. 打开成长册，查看新增的学习记录。

## 8. 第一阶段排期与验收

### 8.1 排期假设

按 1 名 Swift 工程师全职开发，产品／设计与内容人员同步支持，建议安排 4 周。内容审核和录音应同步推进。

若只有一人同时承担开发、设计、释义编写与录音，建议调整为 6—8 周。

### 8.2 四周排期

| 时间 | 主要工作 | 可验收结果 |
| --- | --- | --- |
| 第 1 周 | 确定用户范围、页面流程和视觉规范；确定 12 首诗；完成内容数据结构与基础工程；用 2 首诗打通阅读与释义 | 真机可阅读古诗、切换繁简、展开释义 |
| 第 2 周 | 完成 12 首内容；接入双语朗读；实现背诵提示与三类练习 | 一首诗从学习到练习的主流程完整可用 |
| 第 3 周 | 实现学习记录、错题与复习推荐；接入单人飞花令、个人最高分和成长反馈 | 离线学习闭环完整，退出后进度保留 |
| 第 4 周 | 目标年龄学生试用；修正文案、难度与交互；校验读音和题目；适配 iPhone／iPad；整理演示构建 | 稳定、可重复演示的本地 Demo |

“小小诗人”简版仅在第三周结束时 P0 已稳定的情况下加入，否则进入第二阶段。

### 8.3 Demo 验收清单

- [ ] 飞行模式下能够完成全部核心流程。
- [ ] 繁简切换不丢失进度，题目答案不受文字版本影响。
- [ ] 音频、正文、释义对应正确。
- [ ] 退出重启后记录保留，次日可生成复习内容。
- [ ] 练习提供答案解释。
- [ ] 背诵自评与练习成绩明确区分。
- [ ] iPhone／iPad 无文字截断、按钮遮挡等关键问题。
- [ ] 单人飞花令能完成整局并保存个人最高分。
- [ ] 内置诗库以外的输入不会直接被判为错误诗句。

### 8.4 用户试用

建议邀请 5—8 名目标年龄学生进行小规模可用性试用，重点观察：

1. 能否独立完成从选诗到巩固的流程。
2. 是否理解释义与错题解释。
3. 是否能在游戏中运用刚学的诗句。
4. 是否愿意再学一首。

试用结果用于调整产品与内容，不能单独证明长期学习效果。

## 9. 后续阶段路线图

先完善长期学习能力，再建设多人系统。

| 阶段 | 建议时长 | 核心目标 | 主要功能 |
| --- | --- | --- | --- |
| 第一阶段：本地 Demo | 4 周 | 验证学习与游戏闭环 | 12 首诗、释义、朗读、背诵、小测、复习、单人飞花令 |
| 第二阶段：学习试用版 | 追加 4—6 周 | 验证持续使用与复习效果 | 扩充诗库、完善复习、创作诗集、家长视图、Go 内容服务、可选账号与云同步 |
| 第三阶段：社交游戏版 | 追加 6—8 周 | 验证同伴互动能否促进学习 | 私密房间、多人飞花令、合作挑战、好友／班级榜、服务端判题 |
| 第四阶段：学校与进阶版 | 按试点结果排期 | 支持教学组织与中学深度学习 | 教师布置任务、学校篇目、班级报告、比较阅读、格律学习 |

后续时长按 Swift 与 Go 开发可以并行估算，并需要设计、内容和测试支持。具体需求应根据前一阶段的试用结果再拆分与估时。

多人游戏进入开发前，需要明确轮次、答案有效性、重复答案判定、计分、超时与断线处理规则。

## 11. 技术方案建议

### 11.1 第一阶段：完全本地

| 模块 | 建议方案 |
| --- | --- |
| 界面 | SwiftUI，兼顾 iPhone／iPad |
| 内容 | App 内置 JSON，包含古诗、释义、题目、主题与意象标签 |
| 本地记录 | 若最低版本为 iOS 17+，使用 SwiftData；否则评估 Core Data |
| 多语言 | String Catalog 管理界面文案，内容单独维护繁简版本 |
| 音频 | AVFoundation 播放内置音频 |
| 游戏判题 | 本地诗句索引与确定性规则 |
| 复习 | 本地规则调度，例如初次通过后第 1、3、7 天复习，答错则提前 |

复习间隔为第一阶段的可调整规则，不视为对所有用户都有效的既定结论。

数据从第一阶段起保留稳定的 `poemID`、`lineID`、`questionID` 和内容版本，避免修订内容或接入云同步时丢失学习记录。繁简版本共用同一组内容 ID。

### 11.2 后续 Go 服务

第二阶段先承担内容管理、内容更新、账号与进度同步。第三阶段再加入多人房间、服务端计分和排行榜；对战结果由服务端验证。

第一阶段不以搭建后端为前置条件，客户端的本地内容与记录结构应能够延续到后续阶段。

## 12. 当前建议锁定的交付组合

**12 首精品古诗＋逐句释义＋粤普朗读＋背诵与小测＋本地复习＋单人飞花令。**

该组合用于展示产品核心价值，并为后续创作、多人游戏和学校场景保留可延续的内容与数据基础。
