# Pumpkin Poems 演示清单

更新：2026-11-18。使用普通直板 iPhone。入口：**今天 → 诗词游乐园**。主线是“读懂 → 回想 → 玩起来 → 自己表达”。

## 展示前

- 选好语言：「我的 → 设置 → 学习语言」中选粤语或普通话，分别试听一句；繁简字形可在同页「文字与朗读」独立调整。首次选择保留，之后统一在设置修改语言和字形。
- 首次打开先选目标年级和学习语言；年级覆盖小一至小六、中一至中六，之后可在「我的 → 设置」修改。「今天」可打开学习计划，查看下一首及完成进度。
- 为游戏选好诗库，保存为「演示诗库」。首次建议多选几个作者或使用全部诗库；开始按钮亮起后即可开局。
- 游乐园以 2×2 卡片展示，前三张使用对应游戏的实际画面截图，可点进游玩；第四张为「敬请期待」，暂不可进入。
- 游戏里的声音菜单可分别控制背景音乐、音效、轻震，默认开启；寻诗逐字朗读可单独打开。
- 在最终 iPhone 上试一次拖拽、飘字点按、音乐与朗读。保留已有学习记录，不必重置。

## 我要展示什么？怎么说？

建议主讲 5–6 分钟，另留 2 分钟给对方操作。

| 环节 | 操作 | 普通话讲法 | 粤语讲法 |
| --- | --- | --- | --- |
| 计划，约 30 秒 | 首次选择年级和语言；在「今天」打开学习计划 | “先选年级和学习语言，贝贝会安排合适的诗。年级可以随时修改，学习进度会保留。” | 「先揀年級同學習語言，貝貝會安排合適嘅詩。年級可以隨時改，學習進度會保留。」 |
| 读懂，约 1 分钟 | 打开《静夜思》，播放一句，点「疑是地上霜」看释义；切换背诵遮字 | “先听懂、读懂，再减少提示，让孩子自己想起来。” | 「先聽明、讀明，再收起啲提示，等小朋友自己諗返起。」 |
| 反馈，约 1 分钟 | 小测故意答错一题，查看解释；完成后看实际成绩与复习安排 | “答错会告诉你为什么，之后还能重新练习。” | 「答錯會話你知點解，之後仲可以再練。」 |
| 选库，约 30 秒 | 打开寻诗或猜诗的诗库选择，按学段／作者／诗体选诗，保存「演示诗库」 | “挑战范围由你选，也可以保存自己的诗库，下次继续用。” | 「挑戰邊啲詩由你揀，仲可以儲低自己嘅詩庫，下次再玩。」 |
| 飞花令，约 1 分钟 | 选「月」，依次接住飘字补完空格；点「提示」看出处，再试「补一个字」 | “接住飘落的字，把诗句补完整。想不起来时，先看出处，还可以补一个字。” | 「接住飄落嚟嘅字，補返成句詩。諗唔起嗰陣，先睇出處，仲可以補一個字。」 |
| 划字寻诗，约 45 秒 | 选诗库和字盘，按住首字横竖连接，转弯后松手；展示找到的出处 | “横着或竖着划出整句，可以转弯，也可以在同一行或同一列跨格；不能斜连，同一句不重复用格子。” | 「橫住或者直住劃返成句，可以轉彎，同一行或者同一列可以跨格；唔可以斜連，同一句唔用返同一格。」 |
| 六轮猜诗，约 45 秒 | 选诗库和五言／七言；输入一句库内诗句，提交后依据颜色调整 | “每次都要猜真实诗句。绿色位置对，黄色换位置，灰色排除；最多六轮。” | 「每次都要估真嘅詩句。綠色位置啱，黃色要換位，灰色可以排除；最多六輪。」 |
| 双语言，约 30 秒 | 到「我的 → 设置」切换粤语／普通话，返回原诗再听同一句 | “语言和繁简字形统一在设置里调整，刚才的记录会保留。” | 「語言同繁簡字形統一喺設定度調整，頭先嘅紀錄會保留。」 |

有额外时间，再打开「小小诗人」：选意象，写两句，起名保存并试听。

## 如何让对方上手游玩，领略核心？

交出手机，说：**“你想接住字补诗、划字找诗，还是用颜色猜诗？”** 粤语可说：「你想接字補詩、劃字搵詩，定跟顏色估詩？」

| 对方选择 | 给他的一个小任务 | 卡住时怎样引导 |
| --- | --- | --- |
| 飞花令 | 补完整一句 | “点提示，先看诗名和作者；还没想起来，就补一个字再接着想。” |
| 划字寻诗 | 找到一句，并指出它在哪首诗里 | “先看出处线索，找到第一个字，再横着或竖着连接；需要时转弯，不能斜连。” |
| 六轮猜诗 | 猜两轮，解释第二轮为什么换这句 | “哪几个字能排除？黄色的字还能放在哪里？” |

两分钟只求完成一个小任务。不要替对方点击；最后问：“哪条线索帮到你？”核心是让他经历**自己想 → 尝试 → 看反馈 → 调整**。

## 本版游戏规则

- 飞花令用自己的题库，预设为具体景物字；每局六句。飞字位置保留，依次填其余空格；符合相同模板的其他真实诗句也可得分，本局重复句不重复计分。提示分两步：先显示诗名和作者，再补一个正确字；每题可补一个字，补字保留到本题结束。答案相关字更容易出现；下落速度 56pt/s，普通状态固定每 1.8 秒出一字、稳定时最多 4 个字；摇一摇后短时增加到最多 7 个，可见字去重且保持间距。点中只让该字消失，答错自动清空自己填的字。15 秒未选字会提示摇一摇。
- 寻诗和猜诗必须先选挑战诗库。可以按学段、作者、诗体分类，也可以逐首勾选；命名保存后可再次加载。现有来源按学段提供分类，对应小一至小三、小四至小六、中一至中三、中四至中六。
- 诗库不足以组成所选玩法时，开局前提示多选一些诗。不会悄悄把未选诗加入关卡。
- 寻诗使用拖拽，松手提交；每一步横向或纵向连接，可转弯、可在同行同列跨格，禁止斜向连接。同一句中同格只用一次，重复字要用不同格子；可以回拖撤销最后一步。
- 猜诗选五言或七言，从 4–5 首诗中取句，其中 3–4 句共享字；候选键盘去重后为 20–30 字，不足时从所选库补充。输入必须是所选库里的完整诗句，不成立时不消耗轮次。重复字先判正确位置，再按剩余数量判黄／灰。
- 背景音乐、音效和轻震可独立关闭。朗读时音乐会降低音量，离开游戏或进入后台时暂停。

## 启动与检查

在项目根目录运行：

```sh
./pumpkin-poems-app/scripts/demo.sh cantonese --route games
./pumpkin-poems-app/scripts/demo.sh mandarin --no-build --route games
```

脚本自动选择普通 iPhone，排除 iPhone Duo，保留已有记录。可用 `--device <UDID>` 指定模拟器。最低 iOS 17。

```sh
./pumpkin-poems-app/scripts/run_logic_tests.sh
./pumpkin-poems-app/scripts/run_progress_tests.sh
python3 pumpkin-poems-app/scripts/build_game_content.py
python3 pumpkin-poems-app/scripts/build_game_audio.py
```

精讲学习库为 12 首、60 题；游戏素材为 163 首诗的 1,012 条五言／七言诗句。学习记录、收藏、作品和保存的游戏诗库均在本机；系统语音初次下载需要网络。

小学学习计划按现有来源分为小一至小三、小四至小六两个学段，同学段年级共用对应诗库。学习顺序和复习日期依据已有进度更新。切换年级只调整计划范围，成长册继续展示累计成果。中学年级选项和接口已接入，教学内容整合记录为代码 TODO；界面可直接打开现有诗库选诗，不显示开发说明。

## 安装到自己的 iPhone

自己展示或测试，最方便的是用 Xcode 直接安装，免费 Apple Account 即可。当前项目最低支持 iOS 17。

1. 用数据线连接 iPhone 和 Mac，解锁手机，按提示信任这台 Mac。
2. 在 Xcode 打开 `pumpkin-poems-app/pumpkin-poems-app.xcodeproj`。在 `Xcode → Settings → Apple Accounts` 登录自己的 Apple Account。
3. 选择 App target 的 `Signing & Capabilities`，开启 `Automatically manage signing`，把 `Team` 选为自己的团队／Personal Team。项目目前已有团队配置，需要确认属于你可用的账号；若 Bundle Identifier 冲突，改成你自己的唯一标识。
4. 在 Xcode 顶部运行目标选择你的真实 iPhone。按照 Device Hub 的提示配对，并在手机的 `设置 → 隐私与安全性 → 开发者模式` 开启后重启确认。这个选项可能要配对后才出现。
5. 在 Xcode 按 `⌘R`，会编译、签名、安装并运行 App。之后可以在手机桌面打开。

免费 Personal Team 的签名配置有效期为 7 天，到期后通过 Xcode 重新编译安装。无需为自己试玩而购买开发者会员。后续如需分发给其他人测试，可使用 Apple Developer Program 和 TestFlight；TestFlight 每个测试构建最长可使用 90 天。

参考：[Apple 真机运行与签名说明](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices)、[开发者模式](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)、[免费 Personal Team 限制](https://developer.apple.com/help/account/basics/about-your-developer-account)、[TestFlight](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)。
